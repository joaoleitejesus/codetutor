# CodeTutor

O CodeTutor é uma aplicação web educacional voltada para iniciantes em Python. Seu objetivo é ajudar estudantes a identificar dificuldades, praticar programação com exercícios progressivos e compreender seus erros por meio de dicas e explicações.

## Objetivos

- Identificar dificuldades iniciais por meio de um diagnóstico.
- Oferecer exercícios organizados por assunto e nível.
- Fornecer correção automática, dicas progressivas e explicações.
- Acompanhar o desempenho e a evolução do estudante.

## Tecnologias

- Python
- Streamlit
- JSON
- SQLite
- Git e GitHub
